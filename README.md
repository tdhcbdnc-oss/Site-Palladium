# Palladium — сайт

AI-интегратор. Статический сайт на GitHub Pages, домен palladium.com.ru (HTTPS).

## Страницы

| Файл | Страница |
|---|---|
| `index.html` | Главная — модель работы, направления, лестница, процесс, команда, FAQ, контакты |
| `cases.html` | Кейсы: недвижимость, видеопродакшн |
| `products.html` | Каталог 12 продуктов по четырём ступеням |

## Как устроено

Страницы — offline-экспорт из Claude Design. Каждая самодостаточна: дизайн-система,
шрифты и React 18.3.1 вшиты внутрь файла и раздаются через blob-URL из карты
`window.__resources`. Внешних сетевых запросов нет, кроме Яндекс.Метрики
(счётчик 111244444); ссылки на t.me и unpkg.com в коде — это ключи карты ресурсов
и контактные ссылки, не загрузки.

`.nojekyll` обязателен: без него GitHub Pages прогоняет сборку через Jekyll.

## Обновление сайта

Править контент — в Claude Design, затем выгрузить **offline-версии** всех трёх
страниц (не `.dc.html`) в iCloud Drive и запустить сборку:

```
python3 build/build.py
git diff        # посмотреть, что поменялось
git add -A && git commit && git push
python3 build/indexnow.py   # после деплоя: сообщить Яндексу и Bing об изменениях
```

`build/build.py` делает всё сам: переименование, переписывание внутренних ссылок,
статический `<head>` (title, description, canonical, og/twitter-превью), JSON-LD,
SEO-пререндер, правки консистентности текста, скрипт-хранитель, Метрику,
robots.txt и sitemap.xml. Подробности — в шапке самого скрипта.

Пререндеры в `build/prerender/*.html` — семантические копии контента страниц.
**После содержательных правок в канвасе их надо обновлять руками**, иначе роботы
без JS будут видеть устаревший текст.

## Что делает скрипт-хранитель (вшивается сборкой перед `</body>`)

Рантайм при загрузке полностью заменяет `documentElement` и стирает всё
статическое, поэтому скрипт возвращает и держит:

1. **Мета-теги и title** — иначе после свапа страница остаётся без описания.
2. **JSON-LD** — Google читает разметку из отрендеренного DOM.
3. **Подсказку прокрутки** в строке навигации (`i.pd-hint` внутри строки;
   обёртку ставить нельзя — ломает перенос навигации на мобильном; слушатели
   на `document`, синхронизация по таймеру).
4. **Гашение редакторских артефактов** в пустых `image-slot` (через
   `::part(empty)` и стиль в shadow root).
5. **Карточку WhatsApp** в контактах — карточка «Сайт» переделывается в прямую
   ссылку wa.me с готовым сообщением.
6. **Якорную навигацию** — свап съедает переход по `/#kontakty`, а браузерный
   smooth-скролл гибнет на перерисовках рантайма (секции раскрываются только
   при прокрутке через них). Скрипт скроллит сам, покадрово, с пересчётом цели
   каждый кадр; действия пользователя отменяют.

## Незакрытое

Четыре слота под изображения пустые — `pd-team` на главной, `pd-case1`, `pd-case2-a`,
`pd-case2-b` в кейсах. Картинки хранятся в `.image-slots.state.json`, которого
в экспорте нет — загружать в канвасе Claude Design до выгрузки.
