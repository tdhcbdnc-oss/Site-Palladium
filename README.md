# Palladium — сайт

AI-интегратор. Статический сайт на GitHub Pages, домен palladium.com.ru.

## Страницы

| Файл | Страница |
|---|---|
| `index.html` | Главная — модель работы, направления, лестница, процесс, команда, FAQ, контакты |
| `cases.html` | Кейсы: недвижимость, видеопродакшн |
| `products.html` | Каталог 12 продуктов по четырём ступеням |

## Как устроено

Страницы — offline-экспорт из Claude Design. Каждая самодостаточна: дизайн-система,
шрифты и React 18.3.1 вшиты внутрь файла и раздаются через blob-URL из карты
`window.__resources`. Внешних сетевых запросов нет (ссылки на t.me и unpkg.com
в коде — это ключи карты ресурсов и контактные ссылки, не загрузки).

`.nojekyll` обязателен: без него GitHub Pages прогоняет сборку через Jekyll.

## Правки

Править надо в Claude Design, затем заново выгружать offline-версии. После выгрузки:

1. Переименовать: `Palladium Site (offline).html` → `index.html`, `Cases` → `cases.html`, `Products` → `products.html`
2. Переписать внутренние ссылки: `Palladium%20Site.dc.html` → `index.html` и т.д. — они остаются
   в экспорте в экранированном виде внутри JS-строк
3. Вернуть блок `<script>` перед `</body>`, который восстанавливает title и мета-теги:
   рантайм пересобирает `<head>` при загрузке и стирает всё, что вписано статически

## Незакрытое

Четыре слота под изображения пустые — `pd-team` на главной, `pd-case1`, `pd-case2-a`,
`pd-case2-b` в кейсах. Картинки хранятся в `.image-slots.state.json`, которого в экспорте нет.

## Правки поверх экспорта

Скрипт перед `</body>` кроме мета-тегов делает две вещи:

1. **Подсказка прокрутки** в строке навигации (`[data-navlinks]`) — градиент у правого края,
   виден только когда есть скрытые пункты. Реализован липким нулевым элементом `i.pd-hint`
   внутри строки: обёртку ставить нельзя, она ломает перенос навигации на вторую строку.
   Слушатели висят на `document` (capture) и синхронизация идёт по таймеру — рантайм
   пересобирает навигацию, и всё, привязанное к конкретному узлу, отваливается.
2. **Гашение редакторских артефактов** в пустых слотах `image-slot`: заглушка
   «перетащите файл» и кнопки Replace/Edit приезжают из экспорта и видны посетителям.
   Убираются через `::part(empty)` и стиль, вставляемый в shadow root.

Обе правки живут только в собранных файлах — после нового экспорта их надо накатывать заново.
