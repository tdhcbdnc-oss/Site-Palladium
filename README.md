# Palladium — сайт

AI-интегратор. Статический сайт, публикуется через GitHub Pages.

## Страницы

| Файл | Страница |
|---|---|
| `index.html` | Главная — лестница 12 ступеней |
| `steps.html` | Каталог 12 продуктов |
| `services.html` | 8 модулей и услуг |
| `animations.html` | Библиотека анимаций |
| `orch-16x9.html` / `orch-9x16.html` | Оркестрация, два формата (самодостаточные) |

## Как устроено

Страницы собираются в браузере рантаймом `support.js` (dc-runtime) на React 18.
React и ReactDOM лежат локально в `vendor/` — сторонних CDN нет, кроме Google Fonts.
Хэши SRI в `support.js` соответствуют файлам в `vendor/`: если обновляешь React,
пересчитай их (`openssl dgst -sha384 -binary f.js | openssl base64 -A`).

Исходники дизайна — в архиве `Анимации для футуристичного бренда.zip`.
